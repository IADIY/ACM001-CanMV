# ACM001-CanMV
ACM001 is an programmable AI Camera Module for edge AI applications built under the K230D CanMV project. Providing a staggering 6 TOPS of dedicated Edge AI performance, the AI camera module integrates the processor and camera into a compact 38mm x 38mm board, ideal for high-volume deployment in various edge AI applications.

Engineered for full developer control, the module supports C/C++ SDK, Python, and MicroPython, allowing seamless deployment of your proprietary AI models. This flexibility powers next-generation Edge AI solutions and high-precision Machine Vision in Unmanned Aerial Vehicle, assisted driving, security, automation, and robotics.

This is an official repository for the AI camera module from IADIY. Please refer to the following site for detail information.
